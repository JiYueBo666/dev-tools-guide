# 开发工具入门

通过实际问题学习命令行、Git 与常用开发工具。在线阅读：https://jiyuebo666.github.io/dev-tools-guide/

教程从命令行开始，后续内容会沿学习进度补充。`index.html` 是正文，`style.css` 控制页面样式；推送到 `main` 后由 GitHub Pages 发布。


## 网页与 HTTP 教程

入口为 `web.html`。六篇教程沿用任务清单场景，覆盖请求响应、接口设计、缓存、连接、CORS、会话与服务器。

独立观察实验在 `examples/http/HttpPractice.java`，使用 JDK 17+，不连接任务数据库。运行步骤见教程首页。
