6. 切换到 MySQL

前面的接口不用改。只增加一个数据库配置文件，建立专用库，再换启动方式。

建立独立练习库

启动已有 MySQL 容器。使用管理员进入 mysql 客户端后执行下面 SQL。它只创建这一节专用的库、表与账号，不要把库名改成旧任务库。MySQL 容器仍按前面的 Docker 文档运行。

CREATE DATABASE IF NOT EXISTS todo_quick_lab CHARACTER SET utf8mb4;
CREATE USER IF NOT EXISTS 'quick_app'@'%' IDENTIFIED BY 'quick_lab_password';
GRANT SELECT, INSERT, UPDATE, DELETE ON todo_quick_lab.* TO 'quick_app'@'%';
USE todo_quick_lab;
CREATE TABLE IF NOT EXISTS quick_tasks (
  id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  content VARCHAR(200) NOT NULL,
  done BOOLEAN NOT NULL DEFAULT FALSE,
  deleted BOOLEAN NOT NULL DEFAULT FALSE
);

密码是本机练习值。若 quick_app 账号已经存在，CREATE USER IF NOT EXISTS 不会重设它的密码，启动时要用该账号实际密码。应用账号只拿这个库的数据读写权限，建表由上面的管理员完成。

application-mysql.yaml

文件：src/main/resources/application-mysql.yaml

怎么用：这是新增文件，不替换原 application.yaml。保留 ddl-auto: validate。启用 mysql profile 后，它覆盖 H2 的数据源和建表策略。URL 中关闭 TLS 与获取公钥的组合仅用于当前本机 Docker 连接。远程连接需配置验证证书的 TLS。

spring:
  datasource:
    url: ${DB_URL:jdbc:mysql://127.0.0.1:3306/todo_quick_lab?sslMode=DISABLED&allowPublicKeyRetrieval=true}
    username: ${DB_USER:quick_app}
    password: ${DB_PASSWORD}
    hikari:
      maximum-pool-size: 5
      minimum-idle: 1
      connection-timeout: 3000
      max-lifetime: 1500000
  jpa:
    hibernate:
      ddl-auto: validate

用 mysql 配置启动

DB_PASSWORD=quick_lab_password   mvn spring-boot:run -Dspring-boot.run.profiles=mysql

若映射到本机 3307，额外传 DB_URL，写成你自己的 JDBC 地址。若用户名不同，再传 DB_USER。多个变量写在同一启动命令前。

验证数据保留

用第二节的 POST 创建一条任务，记住返回编号。停止 Java，再用上面的 mysql 命令重启，GET 同一编号应仍能查到。观察启动日志确认本次是 mysql profile；没有启用它时仍使用 H2，重启就会清空。

连接池设置这一轮固定值
maximum-pool-size5
minimum-idle1
connection-timeout3000 毫秒
max-lifetime1500000 毫秒

先用这些小规模练习值，不要通过盲目加大连接数处理慢查询。连接数要按实例数累加，并受数据库能力限制。close 会把池化连接归还；连接被长事务占住时，其他请求仍会等。

遇到 Access denied，核对账号密码与授权；Unknown database 核对库名；validate 报缺表或字段不匹配，对照建表语句。不要为了让错误消失，把 ddl-auto 改成 create。
