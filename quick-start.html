SPRING BOOT / 工程速通

1. 建工程并启动

先完成一个能访问的入口。下面的固定内容按原样写。

建目录

mkdir -p ~/code/quick-todo/src/main/java/com/example/quick
mkdir -p ~/code/quick-todo/src/main/resources
cd ~/code/quick-todo

在 VS Code 打开 quick-todo 整个文件夹。后面的终端命令都在这个含 pom.xml 的根目录运行。

pom.xml

文件：pom.xml

怎么用：固定使用下列依赖与版本。暂时只改 artifactId 时，后面的 JAR 文件名也要跟着改；第一轮保持 quick-todo。

<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>
  <parent><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-parent</artifactId><version>4.1.2</version><relativePath/></parent>
  <groupId>com.example</groupId><artifactId>quick-todo</artifactId><version>0.0.1-SNAPSHOT</version>
  <properties><java.version>21</java.version></properties>
  <dependencies>
    <dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-webmvc</artifactId></dependency>
    <dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-validation</artifactId></dependency>
    <dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-webmvc-test</artifactId><scope>test</scope></dependency>
    <dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-data-jpa</artifactId></dependency>
    <dependency><groupId>com.h2database</groupId><artifactId>h2</artifactId><scope>runtime</scope></dependency>
    <dependency><groupId>com.mysql</groupId><artifactId>mysql-connector-j</artifactId><scope>runtime</scope></dependency>
  </dependencies>
  <build><plugins><plugin><groupId>org.springframework.boot</groupId><artifactId>spring-boot-maven-plugin</artifactId></plugin></plugins></build>
</project>

dependencies 里包含 Web、校验、JPA、H2、MySQL 驱动与测试工具。此时一次准备好依赖，后面不用反复改清单。

application.yaml

文件：src/main/resources/application.yaml

怎么用：照写。YAML 冒号后留空格，使用空格缩进。当前 datasource 使用 H2，create-drop 只用于这个内存练习库。

server:
  address: 127.0.0.1
  port: ${PORT:8092}
app:
  api-key: ${APP_API_KEY:local-practice-key}
  web-origin: ${WEB_ORIGIN:http://127.0.0.1:8080}
  requests-per-second: ${REQUESTS_PER_SECOND:60}
  upload-dir: ${UPLOAD_DIR:./uploads}
spring:
  datasource:
    url: jdbc:h2:mem:quicktodo;DB_CLOSE_DELAY=-1
    username: sa
    password: ""
  jpa:
    hibernate:
      ddl-auto: create-drop
    open-in-view: false
  servlet:
    multipart:
      max-file-size: 2MB
      max-request-size: 3MB
logging:
  level:
    root: INFO
    com.example.quick: INFO
  pattern:
    console: "%d{HH:mm:ss} %-5level [%X{requestId}] %logger{24} - %msg%n"

QuickApplication.java

文件：src/main/java/com/example/quick/QuickApplication.java

怎么用：这一阶段照写，不改类名和包名。

package com.example.quick;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
@SpringBootApplication
public class QuickApplication {
    public static void main(String[] args) {
        SpringApplication.run(QuickApplication.class, args);
    }
}

HelloController.java

文件：src/main/java/com/example/quick/HelloController.java

怎么用：保留 @RestController 和 @GetMapping。要改路径，只改 /hello；要改页面文字，只改 return 的字符串。

package com.example.quick;
import org.springframework.web.bind.annotation.*;
@RestController
public class HelloController {
    @GetMapping("/hello")
    public String hello() { return "服务已启动"; }
}

运行并验证

mvn spring-boot:run
# 保持服务运行，另开终端：
curl -i http://127.0.0.1:8092/hello -H 'X-API-Key: local-practice-key'

预期：200，正文“服务已启动”。停止用 Control + C。修改 Java 或 YAML 后，先停止旧进程，再重新运行。若 8092 被占用，用 PORT=8093 mvn spring-boot:run，后续地址也改成 8093。

固定运行命令：mvn spring-boot:run。启动失败先看终端里的第一条实际错误；不要只看最后一行 BUILD FAILURE。
