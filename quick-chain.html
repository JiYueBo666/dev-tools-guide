4. 公共请求处理

把请求编号、日志、访问校验、跨域和限流集中放好。新增两个文件。

RequestFilter.java

文件：src/main/java/com/example/quick/RequestFilter.java

怎么用：第一轮整体照写。它先生成请求编号，放入 request 与 MDC，再检查密钥和限流，然后 chain.doFilter 继续处理；finally 记录耗时并清理 MDC。修改业务接口时不必改这个文件。

package com.example.quick;
import jakarta.servlet.*;
import jakarta.servlet.http.*;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.UUID;
import org.slf4j.*;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;
@Component
public class RequestFilter extends OncePerRequestFilter {
    private static final Logger log = LoggerFactory.getLogger(RequestFilter.class);
    private final byte[] apiKey;
    private final int perSecond;
    private long window = System.currentTimeMillis() / 1000;
    private int count;
    public RequestFilter(@Value("${app.api-key}") String key, @Value("${app.requests-per-second:60}") int limit) {
        if (key.isBlank() || limit < 1) throw new IllegalArgumentException("配置不能为空或小于1");
        this.apiKey = key.getBytes(StandardCharsets.UTF_8);
        this.perSecond = limit;
    }
    // 单进程全局固定窗口；多人/多实例项目需要换成合适的限流组件。
    private synchronized boolean allow() {
        long now = System.currentTimeMillis() / 1000;
        if (now != window) { window = now; count = 0; }
        return ++count <= perSecond;
    }
    private void fail(HttpServletResponse r, int status, String code, String message, String id) throws IOException {
        r.setStatus(status);
        r.setContentType("application/json");
        r.setCharacterEncoding("UTF-8");
        // 参数只取下方固定字符串与服务端生成的 UUID。
        r.getWriter().write("{\"code\":\"" + code + "\",\"message\":\"" + message + "\",\"requestId\":\"" + id + "\"}");
    }
    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException {
        String id = UUID.randomUUID().toString();
        request.setAttribute("requestId", id);
        response.setHeader("X-Request-ID", id);
        MDC.put("requestId", id);
        long start = System.nanoTime();
        try {
            if (request.getMethod().equals("OPTIONS")) { chain.doFilter(request, response); return; }
            String supplied = request.getHeader("X-API-Key");
            if (supplied == null || !MessageDigest.isEqual(apiKey, supplied.getBytes(StandardCharsets.UTF_8))) {
                fail(response, 401, "UNAUTHORIZED", "缺少有效凭证", id); return;
            }
            if (!allow()) {
                response.setHeader("Retry-After", "1");
                fail(response, 429, "RATE_LIMITED", "请求太快，请稍后再试", id); return;
            }
            chain.doFilter(request, response);
        } finally {
            log.info("method={} path={} status={} durationMs={}", request.getMethod(), request.getRequestURI(),
                response.getStatus(), (System.nanoTime() - start)/1_000_000);
            MDC.remove("requestId");
        }
    }
}
这里的鉴权是单密钥入口校验，用于本机工程练习。它不区分不同用户，也不提供用户权限、JWT 或 Session 登录。多人项目请接 Spring Security，并在 Service 中验证任务归属。

WebConfig.java

文件：src/main/java/com/example/quick/WebConfig.java

怎么用：允许的网页来源从 app.web-origin 读取。新增 HTTP 方法或自定义头时，修改对应清单。这里没有启用跨源 Cookie。

package com.example.quick;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.*;
@Configuration
public class WebConfig implements WebMvcConfigurer {
    private final String origin;
    public WebConfig(@Value("${app.web-origin}") String origin) { this.origin = origin; }
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**").allowedOrigins(origin)
                .allowedMethods("GET", "POST", "PATCH", "DELETE", "OPTIONS")
                .allowedHeaders("Content-Type", "X-API-Key").exposedHeaders("X-Request-ID");
    }
}

重启后验证

# 不带密钥：预期 401
curl -i http://127.0.0.1:8092/api/tasks

# 带正确密钥：预期 200，响应带 X-Request-ID
curl -i http://127.0.0.1:8092/api/tasks -H 'X-API-Key: local-practice-key'

# 模拟浏览器预检：预期允许 8080 来源
curl -i -X OPTIONS http://127.0.0.1:8092/api/tasks   -H 'Origin: http://127.0.0.1:8080'   -H 'Access-Control-Request-Method: POST'   -H 'Access-Control-Request-Headers: X-API-Key,Content-Type'

改密钥、来源和限额的固定位置

# 先停止旧服务；下次启动时使用新值
APP_API_KEY=my-local-key WEB_ORIGIN=http://127.0.0.1:5173   REQUESTS_PER_SECOND=10 mvn spring-boot:run

此后请求头改成 X-API-Key: my-local-key。当前限流是单进程全局固定窗口，每秒最多指定次数，超出返回 429 和 Retry-After: 1。多用户或多实例项目不要沿用这个全局计数；需要按用户等维度采用适合的共享限流组件。

下游要取本次请求编号，固定用 request.getAttribute("requestId")。日志自动取 MDC。不要把当前用户放进单例控制器字段，也不要假定新开的异步线程自动拥有这个上下文。
