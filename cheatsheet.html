随用随查 / QUICK REFERENCE

常用命令速查

不用一次记住，遇到问题时回来查。

下面以 Mac 终端为例。命令中的 文件名、仓库地址、容器名 等需要替换成自己的内容。# 后面是说明，不需要单独输入。

快速跳转： 命令行 · Git · 接口请求 · Docker
01 / 终端

命令行

找文件和目录

pwd                    # 我现在在哪个目录
ls                     # 列出当前目录内容
ls -l                  # 查看更详细的信息
cd 目录名              # 进入目录
cd ..                  # 回到上一级目录
cd ~                   # 回到用户主目录

操作文件

mkdir 目录名           # 创建目录
touch 文件名           # 创建空文件，或更新已有文件时间
cat 文件名             # 显示文件内容
cp 原文件 目标文件     # 复制文件
mv 原文件 新名称       # 移动或重命名文件

查找和排查

ls ~ | grep Doc        # 从主目录列表中筛选包含 Doc 的行
echo "$HOME"           # 查看主目录路径
echo "$PATH"           # 查看命令搜索路径
which git              # 查看终端找到的 git 位置
lsof -i :8000          # 查看使用 8000 端口的进程
ps aux | grep python   # 查找包含 python 的进程行

02 / 版本管理

Git

记录修改

git status                 # 查看当前修改和暂存状态
git diff                   # 查看尚未暂存的修改
git add 文件名             # 暂存指定文件
git diff --staged          # 查看已暂存的修改
git commit -m "说明修改"   # 提交暂存区的修改
git log --oneline          # 查看简洁的提交历史

分支与远程仓库

git init                   # 把当前目录初始化为 Git 仓库
git clone 仓库地址         # 下载远程仓库
git switch -c 分支名       # 创建并切换到新分支
git switch main            # 切换到 main 分支
git merge 分支名           # 将该分支合并到当前分支
git pull                   # 获取并整合当前分支的远程更新
git push                   # 推送当前分支的提交

首次推送新分支通常用 git push -u origin 分支名。合并或拉取前，先用 git status 查看当前状态。

03 / 接口调试

接口请求

curl -i https://jsonplaceholder.typicode.com/posts/1
# 发送 GET 请求；-i 同时显示响应头和状态码

curl -i -X POST 'https://jsonplaceholder.typicode.com/posts' \
  -H 'Content-Type: application/json' \
  -d '{"title":"学习接口","userId":1}'
# 发送 JSON：-X 指定方法，-H 添加请求头，-d 提供请求体

04 / 容器

Docker

先启动 Docker Desktop。以下用教程中的 study-redis 作为容器名。

查看与管理

docker info                    # 检查 Docker 引擎是否可连接
docker ps                      # 查看运行中的容器
docker ps -a                   # 查看所有容器，包括已停止的
docker logs study-redis        # 查看容器输出的日志
docker stop study-redis        # 停止容器
docker start study-redis       # 启动已有的容器
docker rm study-redis          # 删除已停止的容器
记住这个区别：run 创建并启动新容器；start 启动已经存在的容器。删除容器前，先确认是否需要保存其中的数据。

启动 Redis 并连接

docker run -d --name study-redis -p 127.0.0.1:6379:6379 redis:7
# 创建并后台运行 Redis；左边 6379 是本机端口，右边是容器端口

docker exec -it study-redis redis-cli
# 在运行中的容器里打开 Redis 客户端

进入 Redis 客户端后：

PING                    # 测试连接，正常返回 PONG
SET course "dev-tools"  # 写入一条数据
GET course              # 读取这条数据
EXIT                    # 退出客户端，容器继续运行

如果容器名已经存在，用 docker start study-redis 启动已有容器；如果端口被占用，先用 lsof -i :6379 查看。
