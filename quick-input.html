3. 输入、错误和上传

先统一失败回复，再接文件上传。下面新增三个文件。

ApiError.java

文件：src/main/java/com/example/quick/ApiError.java

怎么用：固定错误字段为 code、message、requestId。前端可以直接按 code 分支提示。

package com.example.quick;
public record ApiError(String code, String message, Object requestId) {}

ApiErrors.java

文件：src/main/java/com/example/quick/ApiErrors.java

怎么用：固定保留已知 HTTP 错误分类和最后的 500 兜底。新增业务异常时，增加一个对应的 @ExceptionHandler 方法；修改 code 与提示，不把服务器堆栈返回给前端。

package com.example.quick;
import jakarta.servlet.http.HttpServletRequest;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.method.annotation.HandlerMethodValidationException;
import org.springframework.web.method.annotation.MethodArgumentTypeMismatchException;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.multipart.MaxUploadSizeExceededException;
@RestControllerAdvice
public class ApiErrors {
    private static final Logger log = LoggerFactory.getLogger(ApiErrors.class);
    private ResponseEntity<ApiError> reply(int status, String code, String message, HttpServletRequest r) {
        return ResponseEntity.status(status).body(new ApiError(code, message, r.getAttribute("requestId")));
    }
    @ExceptionHandler(TaskService.Missing.class)
    public ResponseEntity<ApiError> missing(HttpServletRequest r) {
        return reply(404, "TASK_NOT_FOUND", "没有找到任务", r);
    }
    @ExceptionHandler({MethodArgumentNotValidException.class, HandlerMethodValidationException.class,
        MethodArgumentTypeMismatchException.class, HttpMessageNotReadableException.class, IllegalArgumentException.class})
    public ResponseEntity<ApiError> invalid(HttpServletRequest r) {
        return reply(400, "INVALID_INPUT", "请检查字段、格式和取值范围", r);
    }
    @ExceptionHandler(MaxUploadSizeExceededException.class)
    public ResponseEntity<ApiError> large(HttpServletRequest r) { return reply(413, "FILE_TOO_LARGE", "文件过大", r); }
    @ExceptionHandler(org.springframework.web.HttpMediaTypeNotSupportedException.class)
    public ResponseEntity<ApiError> media(HttpServletRequest r) { return reply(415, "WRONG_CONTENT_TYPE", "请求类型不支持", r); }
    @ExceptionHandler(org.springframework.web.HttpRequestMethodNotSupportedException.class)
    public ResponseEntity<ApiError> method(org.springframework.web.HttpRequestMethodNotSupportedException e, HttpServletRequest r) {
        return ResponseEntity.status(405).allow(e.getSupportedHttpMethods().toArray(org.springframework.http.HttpMethod[]::new))
            .body(new ApiError("METHOD_NOT_ALLOWED", "请求方法不支持", r.getAttribute("requestId")));
    }
    @ExceptionHandler(org.springframework.web.servlet.resource.NoResourceFoundException.class)
    public ResponseEntity<ApiError> route(HttpServletRequest r) { return reply(404, "ROUTE_NOT_FOUND", "地址不存在", r); }
    @ExceptionHandler(Exception.class)
    public ResponseEntity<ApiError> unexpected(Exception e, HttpServletRequest r) {
        log.error("request failed", e);
        return reply(500, "INTERNAL_ERROR", "操作失败，请稍后重试", r);
    }
}

给请求字段加校验的写法

public record Create(@NotBlank @Size(max=200) String content) {}
public record Change(@NotNull Boolean done) {}

// 方法参数上必须保留 @Valid：
public TaskService.TaskView change(
        @PathVariable @Positive long id,
        @Valid @RequestBody Change input) {
    return service.changeDone(id, input.done());
}

上面是已有 TaskController 的片段，不要重复粘贴成第二份方法。常用规则：必填文字 @NotBlank，必须存在 @NotNull，长度 @Size，数值下限 @Min，正数 @Positive。done 用 Boolean，才能区分“漏填”和“明确传 false”。

UploadController.java

文件：src/main/java/com/example/quick/UploadController.java

怎么用：文件名和方法可照写。保存目录由配置控制。只返回服务端生成的 fileId，不按用户原文件名保存，也不提供自动下载/执行入口。

package com.example.quick;
import java.io.IOException;
import java.nio.file.*;
import java.util.*;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;
@RestController
@RequestMapping("/api/files")
public class UploadController {
    private final Path root;
    public UploadController(@Value("${app.upload-dir}") String dir) { root = Path.of(dir).toAbsolutePath(); }
    @PostMapping
    public ResponseEntity<Map<String, String>> upload(@RequestParam("file") MultipartFile file) throws IOException {
        if (file.isEmpty()) throw new IllegalArgumentException("空文件");
        Files.createDirectories(root);
        String id = UUID.randomUUID().toString();
        try (var input = file.getInputStream()) { Files.copy(input, root.resolve(id)); }
        return ResponseEntity.status(201).body(Map.of("fileId", id));
    }
}

验证错误与上传

# 空内容：预期 400、INVALID_INPUT
curl -i http://127.0.0.1:8092/api/tasks   -H 'X-API-Key: local-practice-key'   -H 'Content-Type: application/json' -d '{"content":" "}'

# 查不存在的任务：预期 404、TASK_NOT_FOUND
curl -i http://127.0.0.1:8092/api/tasks/999999 -H 'X-API-Key: local-practice-key'

# 创建一个练习文件，再上传：预期 201、fileId
printf '练习附件
' > attachment.txt
curl -i http://127.0.0.1:8092/api/files   -H 'X-API-Key: local-practice-key' -F 'file=@attachment.txt'

上传文件保存在 ./uploads。配置已限制单文件 2MB、总请求 3MB；空文件返回 400，超限返回 413。这里用于保存附件；要把文件当图片展示或公开下载时，还要增加内容类型检查、权限与安全响应。

成功结构固定：创建/查询/修改直接返回 TaskView；列表返回 {items,total,page,size}；删除返回 204。失败统一返回 ApiError。不要只为个别接口随意加一层 {data:...}。requestId 在下一节接上，之前可以为 null。
